# Miffy Pastel Birthday Adventure v2 🌸

A separate GitHub Pages-ready version of the birthday site.

## Visual direction
Pastel whimsical storybook world with animated rabbits, teddy bears and tiny dinosaurs.
Characters deliberately travel around and overlap the question-card area. Generated original artwork is included as a low-opacity scenic layer.

## Password
Default secret: `princessmiftah`
Change `const SECRET="princessmiftah"` at the top of `script.js` if desired.

## Privacy
No personal photographs are included. The password is a lightweight JavaScript gate, not secure authentication.

## Publish as a completely new repo
Create a new public GitHub repository (example: `miffy-pastel-adventure`), upload everything in this ZIP to the repository root, then Settings > Pages > Deploy from a branch > main > /(root).

Your original `miffy-celebrates` repo/site does not need to be changed.


## V3 interactions
- Tap/click any foreground rabbit, teddy or dinosaur: it swells, pops into sparkly remnants, and a randomly selected baby animal appears in its place.
- Pop sound is synthesized in-browser with Web Audio; there is no external audio file.
- Moving pastel clouds cross the scene and puzzled animals periodically tumble down among the petals.
- Keyboard users can focus animals and activate them with Enter/Space.


## V4
- Falling puzzled animals are now clickable/tappable mid-air.
- They freeze at the tap point, swell, pop with the synthesized bubble sound and sparkles, reincarnate as a random animal, then resume falling without intentionally slowing the animation.
- Background continuously morphs through layered pastel pink, peach, butter-yellow, lavender, blue and mint waves.

## Final build
This final package includes:
- animated pastel-wave background
- moving clouds and falling flowers
- clickable foreground animals
- clickable puzzled animals falling from clouds
- swell -> bubble pop sound -> sparkly remnants -> random newborn animal interaction
- dark berry-pink headings and deep midnight-blue text for readability
- all birthday quiz questions, forced-correct progression, ending message and password gate
- no personal photographs
