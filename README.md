# Miffy Pastel Birthday Adventure v2 🌸

A separate GitHub Pages-ready version of the birthday site.

## Visual direction
Pastel whimsical storybook world with animated rabbits, teddy bears and tiny dinosaurs.
Characters deliberately travel around and overlap the question-card area. Generated original artwork is included as a low-opacity scenic layer.

## Password
Default secret: `princessmiftah`
Change `const SECRET="princessmiftah"` at the top of `script.js` if desired.

## Privacy
No personal photographs are included. The password is a lightweight JavaScript gate, not secure authentication.

## Publish as a completely new repo
Create a new public GitHub repository (example: `miffy-pastel-adventure`), upload everything in this ZIP to the repository root, then Settings > Pages > Deploy from a branch > main > /(root).

Your original `miffy-celebrates` repo/site does not need to be changed.
